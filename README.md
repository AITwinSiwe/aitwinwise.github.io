# 孪灵科技官网

科学计算、AI 与数字孪生技术展示网站。使用原生 HTML、CSS 和 JavaScript，可直接通过 GitHub Pages 发布，无需构建或后端服务。

官网：[https://aitwinwise.github.io/](https://aitwinwise.github.io/)

## 页面内容

- 深蓝科学计算主视觉，气象新能源与本地大模型服务入口。
- 科研智能体、教学智能体的写实科技风横向功能图与产品介绍，支持查看高清原图。
- 本地大模型部署、知识库、系统接入与运维。
- 数值模拟、遥感 GIS、AI 与平台工程能力。
- 低空航道规划、气象预警、城市与建筑气流 CFD 建模。
- 新能源合作拓展、环境健康与世界模型研究方向。

## 本地预览

在仓库目录运行 `python -m http.server 4179 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:4179/`。

## 维护

- `index.html`：内容、导航与联系入口。
- `styles.css`：响应式设计与视觉样式。
- `script.js`：移动导航、产品详情、沟通摘要。
- `assets/`：本地图片、图标与字体。来源和授权见 `ASSETS.md`。
- `design-qa.md`：本次视觉与交互验收记录。

联系区域提供 blueingel@hotmail.com 和扫码联系。摘要在本机生成，可打开邮件客户端并填入主题与正文，由访客确认发送；网站不保存表单或自动发送消息。

科研与教学展示使用写实机器人 Agent 连接功能模块或师生工作场景，配图约 2.5:1，无顶部步骤流程或产品品牌名。卡片与详情弹窗均采用深蓝科技配色，功能文字另有 HTML 说明。配图不代表真实软件界面、实际产品硬件、项目现场或仿真结果。新能源属于合作拓展方向，不表述为已验证的成熟预测产品。
